# 0.3.1 알파 패치

이 버전은 실계정별 완전 검증을 기다리는 대신, 제한을 명시한 조회 기능을 테스터에게 열고 오류를 관찰하는 버전이다.

## 새로 열리는 연결

경기·인천의 삼천리 고객은 공급사 선택에서 삼천리를 고르고 개인회원 아이디와 비밀번호로 실험적 조회를 시도할 수 있다. 로그인, 계약 선택, 현재 월을 포함한 24개월 청구 조회를 수행한다. 정보가 존재하는 달만 가져온다.

계량기 누적 지침과 보정된 청구 사용량을 섞지 않는다. 날짜·지침·계량기가 충분한 이력만 추정 계산에 사용한다. 불완전한 청구는 월별 참고 자료로 보관하며 단위가 불분명한 청구 사용량을 m³로 표시하지 않는다. 기존 실측은 보존한다.

삼천리는 조회 전용이다. 검침 제출과 제출 알림은 제공하지 않는다. 계정마다 실제 응답이 다를 수 있고 연결이 실패할 수 있다. 조회 실패만으로 기존 이력을 지우거나 빈 값으로 대체하지 않는다.

## 오류 확인

- 연결 오류 화면과 설정, 최초 시작 화면에서 진단 기록을 열 수 있다.
- 오류 단계, 분류, HTTP 상태와 진단 ID를 표시한다.
- 기기에 최대 100건 보관하며 서버로 자동 전송하지 않는다.
- 아이디·비밀번호·토큰·고객번호·청구 원문·원본 예외 내용은 기록하지 않는다.
- 사용자가 기록을 확인한 후 복사해 이슈에 붙이거나 삭제할 수 있다.

연결 문제를 신고할 때 앱 버전, 공급사, 어떤 버튼을 눌렀는지, 진단 기록을 알려주면 된다. 비밀번호나 고객번호, 청구서·백업 파일은 공개 이슈에 올리지 않는다.

## 기존 기능

SK E&S와 Gasapp의 자동 재전송 차단 및 제출 전 저장 상태 재확인도 포함한다. 기존 공급사 HTTP 오류와 백그라운드 조회 오류에도 진단 기록을 추가했다. EnergyTalk이나 해양·대성 계열 연결은 이번 버전에 포함하지 않는다.

이 변경은 0.3.1, versionCode 8의 배포 준비다. 코드 병합이나 합성 테스트 통과가 Play 업로드 또는 실계정 동작 확인을 뜻하지 않는다.

## 검증 기록

단위 테스트 84개가 통과했다. Android API 35 에뮬레이터에서 XML 결과 기준 화면 테스트 6개가 통과했고 실계정용 테스트 1개는 의도적으로 건너뛰었다. 삼천리 연결 진입·빈 입력 차단·취소, 연결된 상태의 제출 차단, 진단 표시·삭제와 기존 온보딩·백업 흐름을 포함한다. lint 오류는 0개이며 경고는 별도로 유지한다.
