# 0.4.0 알파 마이너 업데이트

버전은 0.4.0, versionCode는 10이다. 알파 연결 실험실, 공급사 선택 범위와 추정 정보 표시를 확장하고, 0.3.2 이후 병합된 추정 모델 변경을 포함한다.

## 사용자 변경 사항

- 첫 시작 화면과 설정에서 알파 연결 실험실을 제공한다. 본인 계정이나 조회 권한이 있는 고객번호로 매번 동의한 뒤 실행한다.
- 대성청정에너지, 경남에너지, 서라벌도시가스, GSE, 명성파워그린을 공급사 목록에 추가한다. 일반 기록 방식은 직접 입력이며 아래 실험은 기존 자동 연결과 별개다.
- 세종 일부 지역의 충청에너지서비스 선택을 제공하고, MC에너지의 목포도시가스 별칭과 공급사 홈페이지 안내를 정리한다.
- 현재 계량기의 실측값과 당시 저장한 추정값 사이의 평균·최대 절대 차이를 표시한다. 최근 90일 중 최대 12일, 서로 다른 날 3회 이상 비교가 있을 때만 수치를 보여준다.
- PR #44의 최근 실측 기울기 중앙값 계산, 조건부 잔차 보정과 14일 혼합 감쇠 개선을 포함한다. 실제 가구에서 정확도가 향상됐다는 주장은 하지 않는다.

## 연결 실험실에서 시험할 수 있는 기능

| 경로 | 시험 내용 | 결과의 한계 |
| --- | --- | --- |
| 경남에너지 직접 조회 | 고객번호로 고지월, 금액, 보정사용량 m³와 사용열량 MJ 조회 | 현재 고지서 참고용이다. 보정사용량을 실제 지침 차이로 취급하지 않으며 이력에 가져오지 않는다. 빈 결과로 고객번호 유효성을 판단하지 않는다. |
| 대성에너지·대성청정에너지 | 공식 폼에 한 번 로그인 요청 후 월별 요금 페이지의 세션 유사 구조, 표 개수와 제한된 항목명 관찰 | 실제 인증 성공이나 청구 데이터 정확성을 확인하는 검사가 아니다. 계약 선택, 이력 가져오기와 제출은 제공하지 않는다. |
| 에너지톡 | 공식 웹 로그인과 주소 선택 후 사용량·자가검침 상태를 앱 화면에 표시 | 참고용 조회다. 누락된 영역은 미확인으로 남기며 내 기록·추정 모델·제출에 사용하지 않는다. |

에너지톡은 CNCITY, 경남, 귀뚜라미, 미래엔서해, 서라벌, GSE, 참빛원주, 참빛충북, 참빛영동, 참빛영동 동해지점과 참빛속초의 11개 서비스 구분을 제공한다. 지역·지점이 별도 구분되므로 11개 독립 공급사 또는 검증 완료 연동을 뜻하지 않는다.

### 공식 웹 화면과 개인정보

에너지톡·카카오 공식 화면의 로그인, 가입과 약관 동의는 사용자가 직접 진행한다. 앱은 비밀번호를 읽거나 카카오 로그인 코드를 대신 교환하지 않는다. 공식 페이지에서 전달받은 세션은 기기 메모리에서 조회에 사용한다.

공식 웹 화면은 조회 전용이 아니다. 결제와 검침 제출 버튼도 있을 수 있으므로 실험 중에는 누르지 않는다. 앱의 실험 조회에 쓰기 경로가 없다는 사실이 공식 웹사이트의 쓰기 기능을 차단한다는 뜻은 아니다.

정상 종료 시 에너지톡 웹 저장소와 일부 쿠키 삭제를 시도한다. 비정상 종료, 쿠키 경로 등으로 정보가 남을 수 있으며 카카오와 다른 공급사의 로그인 쿠키는 지우지 않는다. 완전한 로그아웃이나 웹 데이터 삭제를 보장하지 않는다. 앱 자체에는 광고·분석·자동 오류 전송 기능이 없지만 공식 웹 서비스에는 해당 서비스의 개인정보 정책이 적용된다.

공급사 직접 조회의 입력값과 실험 결과는 내 기록이나 백업에 저장하지 않는다. 실패 단계와 오류 분류만 기기에 남기며 사용자가 진단 요약을 복사해 공유할 수 있다. 공개 피드백에 비밀번호, 고객번호, 주소나 청구서 화면을 넣지 않는다.

### 테스터 확인 사항

1. 본인 공급사와 조회 권한을 확인하고 해당 경로의 동의 안내를 읽는다.
2. 경남 결과는 공식 고지서의 같은 월·금액·단위와 비교한다. 대성 계열은 페이지 구조 점검이라는 한계를 유지한다.
3. 에너지톡에서는 공급사와 주소를 확인한 뒤 참고용 결과를 공식 화면과 비교한다. 결제나 검침 제출은 하지 않는다.
4. 오류가 나면 임의 고객번호나 다른 사람의 계정으로 반복하지 않고 개인정보 없는 진단 요약과 앱 버전을 전달한다.

## 검증 경계

과거 차이는 현재 추정의 신뢰구간이나 오차 상한이 아니다. 실측 간격과 당시 모델 버전이 달라질 수 있으며 제출 안전성을 보장하지 않는다. 이 표시로 수동·자동 제출 허용 조건을 바꾸지 않는다.

신규 실험의 실제 계정 성공과 공급사별 응답 호환성은 아직 검증되지 않았다. 공개 소스 관찰과 합성 테스트용 응답은 실제 계정의 성공 증거가 아니다. 테스트 구현과 실행 결과도 구분하며 최종 검증 결과는 별도로 확인한다.

실험 결과는 가구 기록에 가져오지 않고 백그라운드 갱신이나 자동 제출을 활성화하지 않는다. 기존 SK E&S·Gasapp의 연결·제출 설정은 유지하며 삼천리의 기존 알파 연결은 조회 전용이다. 해양에너지의 새 인증은 활성화하지 않는다. 실제 제출 검증은 정확한 대상과 값에 대한 별도 승인과 공식 재조회가 필요하다.

## 배포 조건

이 문서는 릴리스 준비 범위이며 Play 업로드나 테스터 제공 완료를 뜻하지 않는다. 단위 테스트, lint, 합성 Android 화면 흐름, 서명 AAB와 정확한 소스 revision의 CI를 확인한 뒤 Closed Alpha 배포 절차를 따른다. APK와 AAB는 GitHub에 게시하지 않는다.
