# 공급사 안내

청구서에 적힌 공급사를 선택해 연결하세요. 같은 지역에서도 공급사가 다를 수 있습니다. 목록에 없거나 연결하지 않으려면 `다른 공급사 / 직접 입력`을 선택해 청구서와 계량기 기록을 직접 관리할 수 있습니다.

이 문서는 0.6.0 소스 기준입니다. Play 업로드·심사·제공 상태와는 별개이며, 설치한 앱에서 표시되는 연결 옵션을 기준으로 이용해 주세요.

## 현재 연결

연결한 계약에서는 청구 이력, 검침 기간과 기존 입력 상태를 확인할 수 있습니다. 검침값은 제출 화면에서 현재 상태를 다시 확인한 뒤 보냅니다. 제출 결과가 바로 표시되지 않으면 `검침 기간 확인`으로 상태를 다시 읽어 주세요.

## SK E&S

부산도시가스, 코원에너지서비스, 충청에너지서비스, 영남에너지서비스 구미, 영남에너지서비스 포항, 전남도시가스, 강원도시가스, 전북에너지서비스를 지원합니다.

공급사 계정으로 로그인하고 계약을 선택하면 청구 이력과 자가검침 상태를 가져옵니다. 검침값은 제출 화면에서 직접 입력하거나, 검침 기간 마지막 날 자동 입력을 별도로 켤 수 있습니다. 자동 입력은 기본 꺼짐이며 로그인 정보 저장, 실제 계량기 확인, 공급사에서 다시 조회한 대상·기간·계량기 일치를 요구합니다. 이전 전송 결과가 불확실하면 자동으로 다시 보내지 않습니다.

8개 SK E&S 공급사의 자동 입력은 기존 공통 클라이언트를 이용하는 알파 기능입니다. 공급사별 실제 계정의 접수 성공을 모두 검증했다는 뜻은 아닙니다. 검침 기간과 접수 결과는 공급사 화면에서도 확인해 주세요. Android의 백그라운드 실행이 지연될 수 있어 정해진 시각의 실행이나 마감 전 제출을 보장하지 않습니다.

## 꾸준히 넓어지는 공급사 연결

가스앱, 삼천리와 EnergyTalk 연결을 사용할 수 있습니다. 처음 연결한 날에도 실제 계량기 숫자를 기록한 뒤 제출할 수 있습니다.

### 가스앱

서울도시가스, 예스코, 인천도시가스, 대륜E&S, 귀뚜라미에너지, JB, 전북도시가스, 군산도시가스, 제주도시가스, 참빛도시가스, 경동도시가스, MC에너지, 미래엔서해에너지, 대화도시가스를 지원합니다.

통신사를 선택하고 휴대전화 본인인증을 마친 뒤 계약을 선택합니다. 청구 요약, 계량기와 자가검침 상태를 가져오며 월별 청구 요약은 기록 화면에도 반영됩니다. 자동 입력은 검침 기간 마지막 날에 현재 상태를 다시 확인한 뒤 한 번만 실행합니다.

### 삼천리

삼천리 홈페이지 계정으로 로그인합니다. 계약, 청구 이력과 자가검침 상태를 확인하고 제출 화면에서 검침값을 직접 보냅니다. 자동 제출은 이번 확장에 포함하지 않습니다.

### EnergyTalk

귀뚜라미에너지, 참빛도시가스, 미래엔서해에너지, CNCITY에너지, 경남에너지, 서라벌도시가스, GSE를 지원합니다.

서비스 지역을 선택한 뒤 공식 EnergyTalk 또는 카카오 로그인 화면에서 로그인하고 주소를 고릅니다. 월별 청구 요약과 자가검침 상태를 확인하고 제출 화면에서 검침값을 직접 보냅니다. 자동 제출은 지원하지 않습니다. 현재 월별 요약을 표시하며, 이를 실제 청구 기간의 누적 지침으로 간주하지 않습니다. 로그인 만료가 확인되면 백그라운드 조회를 중단하고 재연결이 필요합니다.

귀뚜라미에너지, 참빛도시가스와 미래엔서해에너지는 가스앱 또는 EnergyTalk 중 사용 중인 채널을 선택할 수 있습니다.

### 대성에너지와 대성청정에너지

청구서에 적힌 회사를 선택하고 해당 홈페이지 계정으로 로그인합니다. 계약을 고르면 청구 이력과 계량기 정보를 가져옵니다. 검침 기간에는 실제 계량기 숫자를 기록한 뒤 제출 화면에서 직접 입력합니다.

0.6.0부터 로그인 정보를 저장하고 마지막 날 자동 제출을 별도로 켤 수 있습니다. 기본값은 꺼짐이며 최근 실측 제한, 계약·계량기·기간·기존 전송 대조를 적용합니다. 실제 계정의 접수 성공은 별도 검증이 필요한 알파 기능입니다.

### 해양에너지

해양에너지 계정으로 로그인하고 주소에 맞는 계약을 선택합니다. 최근 24개월 청구 이력과 검침 기간을 확인하고, 제출 화면에서 실제 계량기 숫자를 직접 보냅니다. 제출 결과는 공급사 정보를 다시 읽어 확인합니다.

0.6.0부터 대성 계열과 동일한 별도 동의 기반 마지막 날 자동 제출을 제공합니다. 계량기나 로그인 정보가 변경되면 자동 제출은 꺼지고 재동의가 필요합니다. [자동 제출 조건](DIRECT_AUTO_SUBMISSION.md)을 확인해 주세요.

## 직접 입력

명성파워그린을 포함해 어떤 공급사든 직접 입력으로 시작할 수 있습니다. 청구서의 사용 기간과 사용량을 기록하고 계량기의 실제 숫자를 확인하면 사용 흐름과 추정을 볼 수 있습니다.

## 연결이 잘 안 될 때

로그인 정보가 맞는지 확인하고, 공급사 앱이나 홈페이지에서 계약이 정상적으로 보이는지 확인해 주세요. 계약이 여러 개면 현재 거주지의 계약을 선택합니다. 자가검침 기간이 아니거나 이미 입력한 경우에는 제출 대신 상태가 표시됩니다.

로그인 화면에서 멈추면 네트워크와 기기의 날짜 설정을 확인한 뒤 다시 시도해 주세요. 문제가 계속되면 청구서의 공급사 이름과 앱에 표시된 안내를 함께 알려 주세요.
