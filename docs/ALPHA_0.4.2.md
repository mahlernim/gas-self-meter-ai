# 0.4.2 Alpha

검침 화면에서 우리 집 정보를 확인하고 필요한 값을 바로 복사할 수 있습니다.

- 상단에는 공급사 이름을 표시합니다.
- 당월 검침일, 예상 누적 지침과 예상 당월 요금 아래에 우리 집 정보 카드를 모았습니다.
- 조회된 계약번호, 계량기번호와 공급 주소에 항목별 복사 버튼을 제공합니다.
- 최근 조회 날짜와 공급사 정보 갱신 버튼도 같은 카드에서 확인할 수 있습니다.

표시 항목은 공급사와 저장된 정보에 따라 달라집니다. SK E&S 연결은 현재 계약에 해당하는 검침 조회 자료의 계량기번호와 주소를 사용합니다. 가스앱 연결은 고객번호와 사용계약번호를 구분합니다. 내부 식별용 해시나 교체 전 계량기번호를 현재 번호로 표시하지 않습니다.

합성 데이터로 기본 화면과 작은 화면의 확대 글자, 항목별 복사, 앱 재실행 후 표시를 확인했습니다. 공급사 조회와 검침 제출 방식은 이전 버전과 같습니다. 기존 알파의 연동 범위와 검증 한계는 [0.4.1 안내](ALPHA_0.4.1.md)를 참고해 주세요.
