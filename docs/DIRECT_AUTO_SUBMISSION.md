# 대성·해양 마지막 날 자동 제출

2026-09-08 구현. 대성에너지, 대성청정에너지, 해양에너지의 기존 계정 연결과 수동 제출 클라이언트를 재사용한다. 새로운 공급사 API는 추가하지 않는다. 코드·합성 검증과 실제 고객 계정의 접수 성공은 별개다.

설정 화면의 자가검침 자동제출을 별도로 켜야 하며 기본값은 꺼짐이다. 로그인 정보를 기기에 저장해야 한다. 마지막 날에만 동작하며 기본 최근 실측 제한 7일을 유지한다. 실제 값이 없거나 현재 지침을 계산할 수 없으면 보내지 않는다.

같은 연결의 정기 새로고침은 사용자가 켠 자동 제출 설정을 보존한다. 계약·계량기·자격 증명이 바뀌거나 백업에서 복원한 경우에는 다시 동의해야 한다. 계량기 교체가 발견되면 과거 계량기의 실측은 현재 제출 근거가 되지 않는다.

전송 전에 공급사 상태를 다시 읽고, 저장소 트랜잭션 안에서 조건을 재검사하고 pending 기록을 먼저 저장한다. 네트워크 호출 직전에 동의·계정·기록 소유권·현재 계산값·기간을 한 번 더 검사한다. 이번 pending 한 건만 정책 검사에서 제외하며 다른 시도는 무시하지 않는다. 전송 후 같은 계약·계량기·기간·값의 접수를 다시 읽어 confirmed로 기록한다. 응답이 없거나 불확실하면 uncertain이며 자동으로 재전송하지 않는다. 거절 기록도 자동 재시도하지 않는다.

워크매니저의 실행 시각과 마감 전 완료는 보장하지 않는다. 마감 당일 결과를 공급사에서도 확인한다. 삼천리와 EnergyTalk의 자동 제출은 이 변경에 포함하지 않으며 기존 직접 확인 제출을 유지한다.

검증은 DirectAutomaticSubmissionTest의 순수 정책/복원 검사와 DirectAutomaticFlowTest의 가짜 클라이언트 기반 Android 저장소 흐름으로 구분한다. 후자는 실제 공급사 요청을 수행하지 않는다. CI 결과는 PR에 기록한다.
