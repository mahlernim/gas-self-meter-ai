# Closed Alpha 0.5.0

버전 코드 13

가스앱, 삼천리, EnergyTalk와 SK E&S 지역 공급사의 연결 흐름을 한곳에서 관리합니다. 계약과 청구 요약, 자가검침 기간을 확인하고 현재 계량기 숫자를 바탕으로 제출할 수 있습니다.

자동 입력은 SK E&S 부산도시가스와 가스앱 연결에서 검침 기간 마지막 날에 사용할 수 있습니다. 삼천리와 EnergyTalk는 제출 화면에서 확인 후 직접 보냅니다.

이번 버전은 Google Play Closed Alpha에서만 제공합니다. 테스터 그룹 가입과 참여 등록을 마친 Google 계정으로 설치하거나 업데이트해 주세요.
