# 0.3.2 알파 패치

저장과 편집 흐름, 접근성을 개선한 알파 업데이트다. versionCode는 9다. 신규 공급사 연결이나 제출 API 변경은 포함하지 않는다.

## 달라지는 점

- 암호화 저장소와 백업 파일, 라이선스, 진단 기록의 IO를 백그라운드에서 실행한다.
- 저장 완료 후 화면을 갱신하며 중복 변경을 막는다. 계량기 교체 성공 후 검침 탭으로 돌아간다.
- 실측과 사용 이력 저장 실패 이유를 모달 내부에 표시한다. 실패한 입력은 모달에 남는다.
- 미지원 공급사는 공식 홈페이지를 안내하고 미연결 공급사는 다시 연결하는 방법을 안내한다. 사용할 수 없는 제출 제어는 숨긴다.
- 설정 토글과 동의 항목은 설명 영역을 함께 누를 수 있고 하나의 접근성 제어로 읽힌다.
- 지역 변경으로 기존 공급사가 유효하지 않게 되면 사용자가 직접 공급사를 고르게 한다.
- 선택 목록에서 현재 값을 표시하고 긴 목록도 선택 위치에서 연다.
- 제출 화면의 중복 추정 계산을 줄이고 보정 문구를 현재 화면에 맞춘다.

## 테스트 범위와 제한

합성 데이터로 저장 순서, 겹친 이력의 오류, 계량기 교체, 제출 안내, 백업 복원과 접근성을 검증한다. 실제 계정 인증이나 검침값 전송은 수행하지 않는다.

삼천리는 계속 실험적 조회 전용이다. SK E&S와 Gasapp의 계정별 호환성 및 실제 제출 검증은 별도 이슈에서 추적한다. 오류를 신고할 때 앱 버전, 공급사, 실행한 동작과 진단 기록을 알려주면 된다. 비밀번호, 고객번호와 백업 원문은 공개 이슈에 올리지 않는다.

코드 병합과 빌드 성공은 Play 배포 완료를 의미하지 않는다. 배포 완료 여부는 Closed Alpha의 테스터 사용 가능 상태로 확인한다. GitHub에는 APK나 AAB를 첨부하지 않는다.
