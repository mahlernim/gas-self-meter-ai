# 실계정 없는 검증 보강

이 문서는 PR #26 당시의 기록이다. 이후 0.3.1 알파 변경에서는 삼천리 조회 화면을 실험적으로 연결했다. 현재 범위는 [알파 패치 안내](ALPHA_0.3.1.md)를 따른다.

2026년 9월 4일, 0.3.0 main 기반의 보강이다.

## 반영 범위

- SK E&S와 Gasapp 모두 같은 검침 주기의 거절된 시도를 자동 재전송하지 않는다. 사용자 수동 재검토는 가능하다.
- SK E&S는 기기 시각보다 미래인 실측을 제출 근거로 사용하지 않는다.
- 수동 SK E&S 제출의 ReentrantLock 구간에서 suspend 전환을 제거한다. 현재 계정과 저장된 판단을 다시 확인하고 pending을 기록한 뒤 전송한다.
- 삼천리 읽기 클라이언트는 온보딩에 연결하지 않는다. 쓰기 endpoint가 없고 리다이렉트와 자동 재연결은 비활성이다.
- 삼천리 파서는 잘못된 월과 숫자, 중복 청구월, 모호한 복수 검침 이력을 거부한다.

삼천리 요청 모델은 공개 고객센터 https://cs.samchully.co.kr/ 의 정적 프런트엔드 조사에 기반한다. 실계정 응답으로 검증한 공식 개발자 API가 아니다. 계량기별 분할 청구와 복수 이력의 선택 기준은 확인될 때까지 지원하지 않는다.

## 테스트

추가 테스트는 저장 코덱 왕복 후 pending·uncertain·confirmed 차단, 거절 후 자동 재시도 차단, 한국 시간 자정과 시계 역행, 삼천리 파서 및 HTTP 실패 경계를 검사한다. 통신 테스트는 application interceptor가 가짜 응답이나 예외를 반환하며 실제 네트워크로 진행하지 않는다.

실제 Android 강제 종료, 디스크 장애, WorkManager 전체 동시 실행과 공급사 제출 후 응답 유실을 재현한 것은 아니다. 인증·고객 조회·SMS·실제 제출은 수행하지 않았다.

## 최신 main과의 통합 판단

제출 후 계약·계량기·기간·실제 값 대조는 이미 main에 있어 유지했다. 기존 GasappApi와 GasappBridge도 유지하며 이전 별도 로컬 Gasapp 읽기 모델을 중복 추가하지 않았다. EnergyTalk의 로컬 실험 코드는 이 변경에 포함하지 않는다. 미검증 기능을 활성화하거나 Play 버전을 변경하지 않는다.

관련 이슈는 #4, #15, #19다. 실계정 완료 조건과 전체 기기 실행 검증이 남아 있으므로 이 변경만으로 닫지 않는다.
